# Alias & Alibi

A privacy-concierge concept for lawful reduction of unnecessary public exposure across business contact information, correspondence and professionally reviewed entity/property questions.

Public source repository: https://github.com/josephjilovec/aliasalibi

## Public experience

- `/` — service overview, privacy principles and professional boundaries.
- `/intake` — scoped intake presentation.

The Nameless Landlord is the proposed property-related service line. Jurisdiction-specific legal, title, fiduciary and disclosure questions require qualified professionals. Privacy work does not remove obligations to legally entitled parties. The public presentation does not establish a functioning private client portal or completed engagements.

## Development

Next.js App Router and TypeScript.

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

Use the existing Vercel project and repository-root configuration. Consult `.env.example` for optional routing variable names; keep any real credentials server-side and outside Git. Do not enable production intake without an approved secure record-handling and professional-routing process.

Detailed service operations, future architecture, provider planning and commercial assumptions are maintained in restricted internal records. This documentation update leaves application source and runtime configuration unchanged. Earlier documentation may remain in public Git history.
